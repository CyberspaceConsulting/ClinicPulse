# Abwesenheiten

Abwesenheiten blockieren Dienstzuweisungen und werden bei [Planungsvorschlägen](planning-suggestions.md) berücksichtigt.

## Arten

| Art      | Hinweis                                    |
| -------- | ------------------------------------------ |
| Urlaub   | muss freigegeben werden                    |
| Krank    | benötigt keine Freigabe                    |
| Sonstige | muss freigegeben werden                    |

Ein Antrag umfasst 1–366 Tage und kann eine Notiz (bis 500 Zeichen) enthalten. Überschneidende Abwesenheiten desselben Mitarbeitenden werden abgelehnt.

## Ablauf

1. Mitarbeitende stellen Anträge für sich selbst; andere Rollen mit Verwaltungsrecht für Abwesenheiten dürfen sie für ihr Team erfassen. Kiosk-Konten haben keinen Zugriff.
2. Offene Anträge können zurückgezogen werden.
3. Berechtigte entscheiden: `approved` oder `rejected`. Eine bereits getroffene Entscheidung lässt sich nicht erneut ändern („Absence was already decided“).
