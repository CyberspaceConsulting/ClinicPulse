# Protokoll und Updates

## Änderungsprotokoll

Änderungen an Konten, Abteilungen, Mitarbeitenden, Schichttypen, Zuweisungen, Abwesenheiten, Archiven, Einstellungen und Backup-Konfiguration werden automatisch protokolliert. Administratoren können das Protokoll abrufen.

## Update-Hinweise

ClinicPulse prüft alle 6 Stunden über die GitHub-Releases, ob eine neuere Version verfügbar ist (aktuelle Version: `CLINICPULSE_VERSION`). Der Administrator wählt einen Update-Kanal. Schlägt die Abfrage fehl (z. B. wegen GitHub-Ratenlimit), wird der Fehler 5 Minuten zwischengespeichert. Updates werden nicht automatisch installiert.

Die manuellen Schritte stehen in der [Docker-Update-Anleitung](../getting-started/update.md).
