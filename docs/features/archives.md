# Plan-Archiv

Abgeschlossene Zeiträume können als unveränderlicher Stand archiviert werden.

- **Manuell:** Berechtigte archivieren einen Zeitraum.
- **Automatisch:** Der Administrator aktiviert die automatische Archivierung und wählt den Zeitraum `monthly` (monatlich) oder `weekly` (wöchentlich). Automatische Einträge erscheinen mit dem Urheber „System (automatisch)“.
- **Nachholen:** Verpasste Zeiträume werden nachträglich archiviert, höchstens 12 Zeiträume je Durchlauf.
- Zeiträume in Abfragen sind auf 1–366 Tage begrenzt.

Der Administrator kann Dienstpläne nicht einsehen; Archive folgen denselben Sichtrechten wie Dienstpläne.
