# ClinicPulse Dokumentation

ClinicPulse ist eine selbst gehostete Webanwendung für die Dienstplanung in Teams mit Schichtbetrieb. Das Projekt befindet sich in einer frühen Alpha-Phase.

> [!WARNING]
> ClinicPulse ist keine produktionsreife Lösung für den Einsatz in Kliniken und keine Rechtskonformitätsgarantie. Bis eine unabhängige Sicherheits- und Datenschutzprüfung erfolgt ist, sollten keine echten Gesundheits-, Beschäftigten- oder sonstigen sensiblen Daten verarbeitet werden.

## Inhalt

- [Installation](installation.md): Start mit Docker Compose, Secrets und Hinweise zum Betrieb
- [Konfiguration](configuration.md): Umgebungsvariablen, SMTP und Verzeichnisse
- [Rollen und Einrichtungsarten](roles.md): Zugriffsrollen und Funktionen je Einrichtungsart
- [Backup und Wiederherstellung](backup.md): Verschlüsselte Sicherungen und Umzug auf eine neue Instanz
- [Architektur](architecture.md): Dienste, Netzwerke und Projektstruktur
